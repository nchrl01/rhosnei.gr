WHAT CONNECTED MEANS
These feeds provide actual native account balances for the visual engine. They are bounded samples, not full holder distributions or total holder counts. Responses keep totalHolders:null and complete:false. Native holder counting is still unavailable. Market prices/charts are separate feeds; an unavailable native-balance feed does not imply that a coin's price chart is unavailable.

Coverage is intentionally specific: DOT is Polkadot Hub EVM accounts, TAO is Bittensor EVM accounts, CFX is eSpace. Hive/Steem use liquid balances; Chia/eCash use full unspent balances for sampled owners; Neo excludes GAS and other NEP-17; VTHO uses energy rather than VET balance. The machine-readable coverage file records each feed's actual scope and timestamps. No seed/default balance substitutes are used.

FREE USAGE AND CACHE
New feeds refresh on demand every two hours; earlier feeds retain their one- or two-hour cadence. One shared Cloudflare cache serves all visitors. Concurrent requests coalesce. Successful old samples retain their real timestamps; samples over six hours old are rejected. No native feed snapshots are persisted in visitors' local storage.

There is a hard global limit of 6,000 upstream requests/day plus provider-specific caps, pacing and persistent cooldowns. HTTP/RPC denials and quotas are respected. This cap bounds source requests; it is not a guarantee that Cloudflare infrastructure itself can never incur costs.

FIXES AND VALIDATION
- Exact asset IDs and distinct cache/capture identities prevent VET/VTHO, THETA/TFUEL, ONT/ONG and RUNE/TCY collisions.
- Ambiguous DATA/PROS/GRX/XP exchange tickers cannot automatically attach another asset's native feed.
- Neo discovers native account keys, then reads current NEO independently; storage values and GAS are ignored.
- Bitkub discovers actual recent transaction senders; Bityuan uses recent account activity. Transfer-token amounts are never used as native balances.
- VTHO includes actual fee payers when delegated transaction origins hold no gas.
- Chia handles transaction-free blocks and discovers ordinary recent outputs before querying full unspent balances.
- Binary and WebSocket responses are bounded; actual Substrate metadata/genesis identities are checked.
- 155 focused history, native-feed, capture, replay/export integrity checks passed. Six workspace typechecks passed. Workspace tests: 18 passed, two existing skips. Website build and actual Worker bundle passed. Clean npm10 root install passed; backend dependencies were installed from the actual Cloudflare build folder.
- A Cloudflare build initially failed because the new SDK dependencies were only listed at the project root. The backend manifest/lock were repaired, deployment succeeded, and CI now installs and bundles that same backend folder.
