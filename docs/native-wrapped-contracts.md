# Native coin contract references

34 native coins have display-only contract or token-identifier references.
The address copies on click; the adjacent arrow opens its explorer or primary
reference. Labels distinguish WRAPPED, BINANCE-PEG, NATIVE and TYPE.
Market data, holders, saves, captures and coin identity remain native.

Verified 2026-10-23. Same-network canonical wrappers are preferred. For BTC,
WBTC on Ethereum is shown. For XRP, DOGE, ADA, LTC, DOT, BCH, ATOM and ETC,
Binance-Peg contracts on BSC are explicitly labelled. These are cross-chain
representations, not native contract addresses or backing/solvency guarantees.

## Activity checks

Registry candidates were cross-checked with exact-address Dexscreener and
GeckoTerminal pool endpoints. See [activity observations](native-contract-activity-2026-10-23.json).
The APIs return bounded pool lists; this is not an exhaustive popularity ranking.
Some networks were not indexed by one service, and the second service rate-limited
later requests. Published protocol contracts remain valid reference evidence;
no activity claims are inferred from rate-limited requests.

The Filecoin 0xce58 candidate had only tiny, inactive pools. The selected WFIL
0x60e177 contract is confirmed by GLIF and Parasail mainnet documentation.
For HBAR, the active SaucerSwap 0x163b5a wrapper was selected over two other
registry candidates with no indexed pools in the first service.
