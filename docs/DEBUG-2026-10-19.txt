WHAT THE FEEDS REPRESENT
These are bounded samples of real native balances for the visual engine. They are NOT total holder counts, a census, or a count of unique people. Every native response retains totalHolders:null and complete:false. Samples can include contracts or exchange custodians. Coverage differs by chain: recent participants, richest addresses or an indexed account page. Some exclude stake, shielded balances or another execution domain; those scopes remain attached to the data.

Source time, index time, balance retrieval time and market-price retrieval time are kept separate. When a source cannot pin an exact balance time, sourceAt remains null. VET was pinned to its provider's finalized block, approximately 68 minutes behind retrieval, and retains that original time. It is not described as a current-second snapshot.

Balance snapshots share a Cloudflare cache across all visitors, refreshing on demand every one or two hours. Samples older than six hours are unusable. Simultaneous requests coalesce. A repeated live SOL request returned cached:true with the original balance timestamp. Browser code keeps native samples in memory; it does not persist them in visitors' local storage.

The relay enforces 3,000 upstream calls/day globally plus separate provider caps, pacing and durable cooldowns. Expected continuous successful demand is approximately 2,556 calls/day, with fewer calls when pages are not requested or samples need fewer reads. Errors can consume that allowance, then the relay waits instead of making unbounded requests. No paid provider subscription or new credential was added. This is not a promise that existing Cloudflare hosting can never incur costs.

FIXES FROM THE DEBUG
1. History retention: saved pages now remain within the 30-day / 1,000-page / 64-MiB limits instead of disappearing when a refresh becomes due. If the provider fails, a previously saved page can be returned with its original time and explicit stale status. Provider cooldown and UPIC's own quota have separate codes. Uncached history still cannot load while the upstream refuses it. Five regression tests pass; a live uncached PEPE request correctly returned PROVIDER_HISTORY_COOLDOWN. A live stale-page response was not observed, so that path is supported by offline regression evidence.
2. Native reliability: provider-specific queues, budgets and cooldowns prevent one failed provider blocking other chains. HTTP420,429 and quota messages delivered as HTTP200 are handled. Quiet/empty feeds wait their normal cache interval. Corrected discovery can retry an older empty result once without bypassing provider denials or budgets.
3. Metadata: shared CoinLore fallback supplies verified native market metadata when CoinGecko is unavailable. Exact ID/slug/symbol matching prevents token confusion. Expired index timestamps and expired market metadata cannot be made fresh by cache reads. Registry additions refresh the shared metadata batch once.
4. XDC/CFX/VET: production failures were resolved with bounded real-data queries and exact network checks. Native and wrapped identities remain separate.
5. Clean install: GitHub's npm10 job exposed two missing utf-8-validate lockfile entries. The lockfile now contains the resolver-generated entries. A fresh npm10.9.9 installation succeeds; existing platform metadata was preserved.

DEPENDENCY AUDIT — OPEN
Production npm audit reports 4 high and 7 moderate package entries, mostly propagated through the Solana wallet dependency tree. Root advisories concern bigint-buffer, stream-json and uuid. Inspection found that the current checked-in browser bundle uses pure-JavaScript bigint conversion, not the affected native binding; stream-json is absent; the Jayson path uses UUIDv4, whereas the cited UUID issue concerns other variants with caller buffers. No matching import path was found in the Worker/API/renderer/server source review. This is not proof that the installed dependency tree is vulnerability-free. The audit remains open.
Do not apply npm's suggested Reown downgrade automatically: it changes the wallet integration's dependency generation. A coordinated wallet dependency upgrade/replacement and wallet regression testing remain necessary.
