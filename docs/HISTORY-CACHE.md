# Thirty-day chart history cache

`history-cache.js` stores DEX and public-exchange candle datasets in this browser's IndexedDB for up to 30 days from saving. Cache identity includes network/pool/base token/timeframe/aggregation for DEX candles, or exchange/symbol/timeframe for exchange candles. Currency remains USD, as in the existing loaders. Original coverage, provider observation times and gaps are preserved.

Existing localStorage entries migrate when their exact key is requested; their timestamp is not reset during migration. No unrelated user storage is removed. Storage failures fall back to fetching, not a broken player. An IndexedDB open that hangs times out after 1.5 seconds.

On reopen, saved candles render before the provider refresh. Completed DEX backfills are reused; partial backfills continue at their oldest edge, and a real gap between the recent page and saved data is bridged. The first latest-page request is reduced to the number of intervals since the latest saved candle, with overlap, bounded at 10–1,000 candles. Very recent complete datasets can skip refresh for 60 seconds. Public-exchange backfills stop once new data overlaps a sufficiently covered saved range. Current candles and live trades continue updating; this cache never freezes a market for a month.

Limits: 64 MiB estimated serialized size, 512 datasets, maximum 16 MiB per dataset, existing DEX 20,000 / exchange 1,200 candle bounds. Oldest-written/expired records are pruned under pressure. A small eight-entry memory cache covers immediate reuse. Browser quota eviction, private browsing or clearing site data can remove cached history sooner.

## Shared Cloudflare layer

DEX/collection-token history now goes through the existing Worker `/history` route and the `HolderCache` Durable Object at a dedicated shared identity (`shared-chart-history-v1`). SQLite stores validated historical pages for 30 days, with 30-second caching of latest pages. This is persistent shared storage, not only an edge cache: different visitors/locations use the same object. Requests for the same page join one in-flight upstream fetch; requested tail sizes share a canonical 1,000-row provider page. Only known OHLCV fields and a fixed GeckoTerminal host are allowed; no API credentials go to the browser. Empty pages are retried after 30 seconds rather than being frozen for a month.

A shared six-second miss spacing and provider cooldown protect free API limits. Reservations are capped at 10,000/day by default (configurable downwards), and a crowded queue returns Retry-After instead of multiplying upstream traffic. Stored pages are bounded at 64 MiB / 1,000 pages; quota pressure can evict older pages sooner than 30 days. Cache hits bypass the browser’s direct-provider queue; backend misses use the shared quota. Latest ticks still come through the existing live feed. Public exchange candle histories retain the browser cache; they have not been moved server-side. No coins are fetched in the background just because they appear in the catalogue.

During backend rollout or an unavailable Worker (404/503), the browser can use the existing direct provider path with its existing request budget. A real 429 quota response is not bypassed. The Worker exposes history retention and fetched-at headers so cached provider observation times are not replaced with a fake current time. Thirty-day retention does not guarantee market-data providers retain or never revise older candles. No schema, coverage or historical-holder data is fabricated.
