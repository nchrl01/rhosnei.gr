ENVION — minimal view for $UPIC

On the website, type pdata in the coin search field to open the instrument.
The compact monitor shows the same ENVION engine that plays the music:

Market clock: the tempo and normalized market signals received by ENVION.
Source material: the loaded preset/sample. Expand Selected files to see the
chosen sample, envelope bank, tape recording and reverb impulse response.
Loading next material means the displayed file selection is still being staged.

Timing: envelope stretch and playback factor. The source random-speed bus
is retained for inspection but has no sound receiver in this version.
Sound layers: granular playback and tape, which can run in parallel.
Filter: left/right cutoff and route switches.
Echo + reverb: volume changes echo; liquidity changes reverb.
Stereo: buy/sell balance controls position; movement can enable autopan.
Output: the measured stereo signal inside ENVION, before the website master
volume. This is a signal meter, not confirmation of speaker output.

Expand a row for its actual control readings. Hover a control label for its
market input; the current value may also include a held chance decision.
Expand Original Pure Data patch to explore the complete source drawing.
These readings are read only. Listen/Pause uses the website's main transport.

The view does not replace DSP, presets, samples, effects, clocks or market
mappings. Every existing Pd patch and sample was retained.

Standalone Pure Data version: see ENVION-Minimal-README.txt in this folder.
